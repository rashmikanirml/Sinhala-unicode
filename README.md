# Singlish to Sinhala/Tamil Offline Desktop App

This app transliterates and translates Singlish (romanized Sinhala/Tamil) into Sinhala and Tamil scripts, fully offline.

## Features
- Transliteration: Singlish → Sinhala/Tamil
- Translation: Singlish → Sinhala/Tamil (offline, local models)
- Desktop UI (Tauri)

## Getting Started
- See requirements.txt for Python dependencies (for prototyping)
- See src-tauri/ for Rust backend
- See src/ for frontend UI
